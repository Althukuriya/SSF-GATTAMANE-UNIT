Every registration is sent straight to a Google Sheet so your team can see entries live. Set it up once — it takes about 3 minutes. A ready-to-use script file is also included alongside this website's download.

  1. Create a new Google Sheet. In row 1, add headers: Timestamp, Name, Phone, Institution, Program, Category (the script also adds these automatically if the sheet is empty).
  2. Go to Extensions → Apps Script, delete the sample code, and paste the script below (or the downloaded .gs file's contents).
  3. Click Deploy → New deployment → Web app. Set "Execute as" to Me and "Who has access" to Anyone.
  4. Copy the deployment URL and paste it into Fest & Programs → Google Sheet Web App URL in this panel, then Save.
function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); if (sheet.getLastRow() === 0) { sheet.appendRow(["Timestamp", "Name", "Phone", "Institution", "Program", "Category"]); } var data = JSON.parse(e.postData.contents); sheet.appendRow([ new Date(), data.name, data.phone, data.institution, data.program, data.category ]); return ContentService.createTextOutput(JSON.stringify({status:"success"})) .setMimeType(ContentService.MimeType.JSON); }

Content is stored in this browser (localStorage). Use Export to back up your content as a file, or Import to restore it on another device/browser.
